# Lab 03 — Assigning Licenses Using Group Membership

**Certification:** Microsoft SC-300  
**Module:** 1 — Implement an Identity Management Solution  
**Platform:** Microsoft Entra ID / Microsoft 365  
**Status:** Completed (update after verifying all exercises)

## Objective
Understand group-based license assignment, Microsoft 365 group management, and dynamic group membership in Microsoft Entra ID.

## Activities
- Created a security group with assigned membership.
- Assigned an Office 365 E3 license to the security group.
- Verified license assignment for a group member.
- Created a Microsoft 365 group with designated owners and members.
- Configured a dynamic security group using attribute-based membership rules.
- Explored rules for filtering guest users and member users.

## Tools Used
- Microsoft Entra admin center
- Microsoft 365 admin center

## Key Takeaways
- Group-based licensing simplifies license management at scale.
- Security groups and Microsoft 365 groups serve different administrative purposes.
- Dynamic group membership automatically adapts to user attributes.
- Group membership and licensing changes may require processing time before taking effect.
