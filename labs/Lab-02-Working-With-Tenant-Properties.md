# Lab 02 — Working with Tenant Properties

**Certification:** Microsoft SC-300  
**Platform:** Microsoft Entra ID / Microsoft 365  
**Status:** Completed

## Objective
Understand how to configure and manage Microsoft Entra ID tenant properties, domain settings, and organizational privacy information.

## Activities
- Explored custom subdomain configuration for the tenant.
- Updated the tenant display name and technical contact.
- Reviewed tenant properties, including country/region, location, and tenant ID.
- Configured the global privacy contact and privacy statement URL.
- Verified accessibility of the organizational privacy statement.

## Tools Used
- Microsoft Entra admin center
- Microsoft 365 admin center
- GitHub (test privacy statement)

## Key Takeaways
- Tenant properties contain important organization-wide configuration and identification information.
- Custom domains and subdomains support organizational identity management.
- Privacy contact information and policy URLs help communicate organizational data-handling practices.
- Tenant configuration requires careful administrative control.
